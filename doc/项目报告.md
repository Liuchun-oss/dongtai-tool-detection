二、项目背景与目标
2.1 背景分析
铁路职工在上道作业前需清点携带工具，传统人工清点方式存在以下问题：
依赖人工记忆，易遗漏
耗时较长，影响作业效率
无电子记录，难以追溯
工具遗漏在线路上存在重大安全隐患
2.2 项目目标
核心目标：通过AI图像识别实现工具自动清点
功能目标：
作业前后拍照对比，自动识别工具缺失
完全离线运行，保护数据安全
完整历史记录，支持追溯查询
一键生成清点报告
性能目标：
识别准确率 > 95%
单次识别时间 < 3秒
支持10+种铁路常用工具识别
三、功能需求规格
3.1 核心功能模块
工具识别模块
支持10类铁路工具识别
适应不同光照条件（自然光/室内灯光）
处理工具部分超出垫布边缘的情况
智能对比模块
作业前后照片自动对比
生成差异报告（缺失工具清单）
可视化展示对比结果
历史管理模块
按时间轴展示清点记录
支持记录查询、删除
数据本地存储，无需网络
报告分享模块
生成可视化对比报告
一键分享至微信等社交平台
报告包含时间、工具清单、缺失项
3.2 工具识别范围
扳手类：大扳手、活口扳手等
钳子类：尖嘴钳、钢丝钳等
螺丝刀：一字、十字、各尺寸
其他工具：风机、防护红旗、喷壶、对讲机、万用表、内六角等
识别策略：按大类识别，不区分子型号
四、技术实施方案
4.1 系统架构设计
应用层：Android原生应用（Kotlin）
  ├─ 相机模块：CameraX框架
  ├─ AI推理模块：TensorFlow Lite + YOLOv8
  ├─ 数据处理模块：Room数据库
  └─ UI展示模块：Jetpack Compose

模型层：YOLOv8目标检测模型
  ├─ 模型格式：TensorFlow Lite（INT8量化）
  ├─ 模型大小：~12MB
  └─ 运行环境：纯离线，无网络依赖

4.3 数据处理流程
用户操作流程：
1. 作业前拍照 → AI识别工具 → 保存工具清单
2. 作业后拍照 → AI识别工具 → 与历史清单对比
3. 生成对比结果 → 保存到历史记录 → 可选分享报告

技术处理流程：
1. 图片采集 → 垫布区域检测 → 图片预处理
2. AI推理 → 工具检测 → 数量统计
3. 数据对比 → 差异分析 → 结果可视化
4. 数据存储 → 历史管理 → 报告生成
