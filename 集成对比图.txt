================================================================================
                        ONNX模型集成 - 前后对比
================================================================================

┌─────────────────────────────────────────────────────────────────────────────┐
│                              集成前 (模拟识别)                               │
└─────────────────────────────────────────────────────────────────────────────┘

  用户拍照
     ↓
  MockToolDetectionService
     ↓
  随机生成工具列表
  (模拟延迟1-2秒)
     ↓
  返回模拟结果
  ["大扳手*2", "活口扳手*1", ...]

  ❌ 问题:
  - 结果完全随机，不准确
  - 无法真实识别工具
  - 仅用于测试UI流程


┌─────────────────────────────────────────────────────────────────────────────┐
│                           集成后 (真实AI识别)                                │
└─────────────────────────────────────────────────────────────────────────────┘

  用户拍照
     ↓
  OnnxToolDetectionService
     ↓
  ┌─────────────────────────────────┐
  │ 1. 加载ONNX模型 (首次)          │
  │    - 从assets读取best.onnx     │
  │    - 初始化ONNX Runtime        │
  │    - 启用NNAPI硬件加速         │
  └─────────────────────────────────┘
     ↓
  ┌─────────────────────────────────┐
  │ 2. 图片预处理                   │
  │    - 读取图片文件               │
  │    - 根据EXIF旋转图片          │
  │    - 调整大小到640x640         │
  │    - 转换为CHW格式             │
  │    - 归一化到[0,1]             │
  └─────────────────────────────────┘
     ↓
  ┌─────────────────────────────────┐
  │ 3. YOLOv8推理                   │
  │    - 运行ONNX模型              │
  │    - 检测24个类别 (A01-A24)    │
  │    - 输出边界框和置信度        │
  └─────────────────────────────────┘
     ↓
  ┌─────────────────────────────────┐
  │ 4. 后处理                       │
  │    - 置信度过滤 (>0.25)        │
  │    - NMS非极大值抑制           │
  │    - 统计每个类别数量          │
  └─────────────────────────────────┘
     ↓
  返回真实识别结果
  ["工具A01*3", "工具A05*2", ...]

  ✅ 优势:
  - 真实AI识别，准确可靠
  - 支持24个工具类别
  - 硬件加速，性能优化
  - 可调整检测阈值
